# Kofi Adofo – Portfolio Website

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository named exactly `Kofi-0.github.io`.
2. Set the repository visibility to **Public**.
3. Upload `index.html` to the top/root level of that repository.
4. Open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait a few minutes. Your site should be available at:
   https://kofi-0.github.io/

## Before publishing
- Check that every skill and proficiency level accurately reflects your abilities.
- Confirm project descriptions and dates. Only keep projects and experience you can discuss confidently.
- Add screenshots, source-code links or demos when you are ready.

The site is a simple static HTML page and does not require a framework or paid hosting.
